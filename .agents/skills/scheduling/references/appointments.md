# Appointments

Select an available slot, select an existing customer or create one through CRM, choose a service and book. Support edit, cancel and reschedule, including dragging between times or eligible people. Manual and WhatsApp-originated requests use the same application rules and entities. Enforce authorization on the backend for every action; interface controls are not enforcement.

Validate customer, service, eligible active person, duration and availability. Cancelled appointments retain history; which other statuses block time remains undecided. Check eligibility and availability again at commit; define a consistency strategy with IAM for concurrent revocation. A failed move preserves the original appointment. Unavailable service handling requires an explicit decision.

Test independent permissions, history retention, unavailable times, overlapping and concurrent bookings, edits, cancellations, reschedules, races and identical rules across channels.
