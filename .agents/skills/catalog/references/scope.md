# Catalog of categories and services

## Scope

These references describe the intended structure of Cynthia's catalog: categories, the services that belong to them, and the order produced by drag and drop.

The references describe intended behavior, not proof of what is implemented. Verify the current behavior before making implementation claims. Rules that remain undefined must not be treated as decided behavior.

The catalog is not the permission hierarchy. A category's `sort_order` only decides where that category appears. A service's `sort_order` only decides where that service appears inside its category. Neither value grants authority over members or groups.

Cynthia's catalog has no employee, HR, or certificate concepts. Do not add them here.
